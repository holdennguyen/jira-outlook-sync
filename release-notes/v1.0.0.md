# Jira-Outlook Sync v1.0.0 🎉

**First stable release of the Jira-Outlook Sync CLI tool!**

## What is this?

A simple, easy-to-use CLI tool that searches your Jira tickets and exports them to calendar files (`.ics`) that you can import into Outlook, Google Calendar, or any calendar app. No complex OAuth setup required!

## ✨ Key Features

- **🔍 Smart Search**: Search Jira tickets by keyword
- **📅 Auto Calendar Export**: Creates `.ics` files with events, reminders, and details
- **👥 Team Invites**: Add team members as attendees to calendar events
- **⚙️ Simple Setup**: Just need your Jira URL and API token (5-minute setup)
- **🖥️ Cross-Platform**: Works on macOS, Windows, and Linux
- **🚀 No Infrastructure**: Runs entirely locally - no servers, no OAuth apps

## 🚀 Quick Start

### Installation

```bash
git clone https://github.com/holdennguyen/jira-outlook-sync.git
cd jira-outlook-sync
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

### First Use

```bash
# 1. Login to Jira
jira-outlook-sync login

# 2. Search and export
jira-outlook-sync search "deployment" --open-file

# 3. Import the .ics file that opens in Outlook!
```

## 📦 What's Included

- **Commands**:
  - `login` - Authenticate with Jira
  - `search` - Search tickets and export to calendar
  - `recipients` - Manage email list for calendar invites
  - `status` - Check authentication status
  - `logout` - Clear credentials

- **Features**:
  - Automatic reminder creation (45 minutes before by default)
  - Support for custom reminder times
  - Email recipient management
  - Automatic file opening after export
  - Custom output file paths
